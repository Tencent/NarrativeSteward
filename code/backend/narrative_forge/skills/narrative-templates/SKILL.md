# 叙事结构模板（弱格式大纲）

为"故事大纲生成"提供结构骨架，并把结果以**自由 Markdown 文本**写入 `/project/outline.md`。
大纲是"概要层"，重在**故事整体走向与关键节点**，不必逐一定义角色/地点细节（那是世界设定阶段的事）。

## 可选叙事结构

- **三幕结构**：建置 → 对抗（含中点转折）→ 结局（高潮与收束）。
- **英雄之旅**：平凡世界 → 冒险召唤 → 试炼与盟友 → 至暗 → 蜕变 → 归来。
- **起承转合**：起（引入）→ 承（发展）→ 转（逆转）→ 合（收束）。

## 步骤

1. 读取依据：先 `read_file /project/intent.md`（创作意图），再 `ls /project/materials` 看有哪些素材并**逐个分页读全**（默认只读前 100 行，用 `offset` 续读至末尾；素材可能多份、也可能为空），把握题材、基调与核心冲突。
2. 依题材与基调选一个结构（或融合），把故事主线映射为幕/章节与关键转折。
3. **以 Markdown 写入** `/project/outline.md`：
   - 文件不存在 → `write_file` 创建。
   - 已存在 → **先 `read_file` 读全现有内容，再用 `edit_file` 只改该改的部分，保留其余既有内容（含用户手改），不要整体重写。**
   - **不要修改 `/project/meta.json`，也不要写 `world.json`。**

## Markdown 结构参考（**仅供参考，不是强制格式**）

```markdown
# 故事大纲

## 核心立意
（一两句话点明主题 / 想让玩家体验到什么）

## 整体走向
（用一段话概述从开端到结局的主线）

## 章节 / 幕
### 第一幕：建置
- 开场情境与核心悬念
- 关键转折：……

### 第二幕：对抗
- 主要冲突推进
- 中点转折：……

### 第三幕：结局
- 高潮
- 收束（可在此标注多结局分支的大致走向）
```

写法要求：
- 自由 Markdown 即可，**无强制 schema**；可读、有层次、有起承转合。
- 概要为主：点到关键人物/地点即可，细节留给世界设定阶段。
- 若创作意图要求"多结局分支"，可在结局处简述主要分支走向。
- 全文用中文。

## 质量自检

- 是否有清晰的核心冲突与主角目标？是否存在中点转折与高潮？
- 整体走向是否连贯、与创作意图一致？篇幅是否适中（概要而非细节堆砌）？

## 输出

写入完成后，只向上层回一段简短摘要（整体走向一句话 + 大致幕/章数），不要复述完整大纲。
